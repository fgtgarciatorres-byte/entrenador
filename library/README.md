# Biblioteca Cancha

La biblioteca contiene fichas breves para usar dentro de Cancha. Cada ficha tiene finalidad práctica, edades, etiquetas y fuentes. Las fuentes completas permanecen en sus páginas oficiales; Cancha conserva metadatos y resúmenes de aplicación para evitar redistribuir material protegido sin autorización.

El agente debe usar una ficha como apoyo, no como instrucción superior. Primero comprueba equipo, categoría, contexto y calidad de datos. En psicología deportiva da orientación educativa al entrenador, sin diagnosticar ni intervenir directamente con una menor.

El validador `tools/validate-cancha.mjs` comprueba catálogo, fuentes, vínculo con el código y consistencia mínima del scouting.
